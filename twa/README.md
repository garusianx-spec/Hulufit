# Android TWA packaging

The web app is already TWA-shaped — `display: standalone`, safe-area padding,
a `/` scope, maskable + monochrome icons and a service worker with an offline
fallback. What lives here is the Android wrapper.

## Files

| File | Purpose |
|---|---|
| `twa-manifest.json` | Bubblewrap's project descriptor — package id, colours, shortcuts, signing key |
| `build.sh` | `init` / `build` / `fingerprint` / `verify` |
| `android.keystore` | **Not committed.** Generated by `build.sh init`; back it up |

## One-off setup

```bash
./twa/build.sh init          # doctor + keystore + android project
./twa/build.sh fingerprint   # SHA-256 for assetlinks.json
```

Paste the fingerprint into [`public/.well-known/assetlinks.json`](../public/.well-known/assetlinks.json),
replacing the placeholders, then **redeploy the web app before building the
APK** — Chrome fetches the statement list at install time.

> If the app ships through **Play App Signing**, Google re-signs it. List both
> the upload key and the Play signing key fingerprint, or users who install
> from Play get a URL bar while your local sideload looks fine.

## Release

```bash
./twa/build.sh build         # → app-release-signed.apk + app-release-bundle.aab
./twa/build.sh verify        # confirms the deployed statement list
```

Upload the `.aab` to the Play Console. The `.apk` is for sideload testing.

## Bumping a version

`appVersionCode` must increase on every upload; `appVersionName` is what users
see. Edit both in `twa-manifest.json`, then `build`.

## Verification checklist

- [ ] No URL bar on launch → asset links resolve for the *installed* signature.
- [ ] Status bar emerald `#059669`; content clears the notch and the gesture bar.
- [ ] Back gesture navigates the SPA rather than closing the app.
- [ ] Airplane mode → `offline.html` renders in Persian in the right face.
- [ ] Long-press the launcher icon → all three manifest shortcuts appear.
- [ ] Share a PDF from another app → HelloFit is offered as a target.
- [ ] The maskable icon is not clipped on circular, squircle and teardrop masks.
- [ ] A 30 MB lab PDF uploads over mobile data without the WebView being killed.
- [ ] A supplement reminder fires with the app closed (requires web push).

## What the wrapper does not do

Notifications still come from the web layer (`public/sw.js`). The TWA forwards
them, but the subscription and the VAPID key are the gateway's job — see
[`docs/notifications.md §5`](../docs/notifications.md).
